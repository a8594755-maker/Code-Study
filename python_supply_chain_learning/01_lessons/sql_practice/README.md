# SQL Practice

This folder is for SQL lessons from zero foundation.

Default database tool: SQLite.

Why SQLite:

- It is lightweight.
- It works well for beginner practice.
- Python includes SQLite support through the built-in `sqlite3` module.
- It is enough for learning analyst SQL concepts before moving to larger databases.

## Learning Order

1. `SELECT` and `FROM`
2. `WHERE`
3. `ORDER BY` and `LIMIT`
4. `GROUP BY`
5. `JOIN`
6. Query SQLite from Python
