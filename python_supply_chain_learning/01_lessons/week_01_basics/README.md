# Week 1: Python Basics

Goal: learn Python from zero foundation by building simple business calculators.

## How this week is organized

One topic = one folder. Inside each day folder, files are numbered in the order you do them:

```text
day1_inventory_cost/
├── 1_example.py    <- read first (complete worked example)
├── 2_practice.py   <- then fill in the blanks
└── 3_blank.py      <- finally write it from scratch, no hints
```

Days 2-6 currently have `1_example.py` only; the practice and blank files are added when you reach that day.

## Day folders (in order)

| Day | Folder | Topic |
| --- | --- | --- |
| 1 | `day1_inventory_cost/` | Inventory cost (total inventory value) |
| 2 | `day2_sales_revenue/` | Sales revenue |
| 3 | `day3_profit/` | Gross profit |
| 4 | `day4_unit_cost/` | Unit cost (division) |
| 5 | `day5_review/` | Review day (rebuild from a blank page) |
| 6 | `day6_two_product/` | Mini project: compare two products |

## Start here

Run all commands from the repo root `python_supply_chain_learning/`.

1. Read `week_01_plan.md` (in this folder) for the full week plan.
2. Read the example: `python3 01_lessons/week_01_basics/day1_inventory_cost/1_example.py`
3. Fill in the practice file: `2_practice.py`, then run it.
4. Write the blank-page version `3_blank.py` from scratch, then run it.
5. Record progress in `02_trackers/learning_log.md` and `02_trackers/progress_tracker.csv`.

Note: file contents are in English; your tutor explains in Traditional Chinese.
